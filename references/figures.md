# 读图与图解规范

## 先看整体，再看面板

1. 读图注第一句：这张图要证明什么。
2. 看图的类型：流程/模式图、结构图、显微图、热图、火山图、箱线图、生存曲线、森林图、散点/回归、柱状图、网络图、模型架构图。
3. 找“对照—处理—读出”：对照是什么？处理是什么？读出指标是什么？样本量 n 是多少？
4. 看图与正文的接口：正文哪一句引用了它（`Figure 3 shows that...`），这句话就是图的核心结论。
5. 最后按 A/B/C… 逐面板拆：每个面板一个小结论，合起来支撑主结论。

## 每张图必须写清

| 字段 | 写什么 | 不要写什么 |
|---|---|---|
| `short` | 8–18 字，读者一眼知道这张图在讲什么 | “Figure 1”“结果图” |
| `one_line` | 一句话结论，能被图直接支持 | “展示了……”这种空话 |
| `legend_zh` | 图例中译，保留 A/B/C 与缩写 | 大段背景介绍 |
| `what` | 坐标轴、分组、颜色、显著性标记、各面板对应关系 | 直接跳到结论 |
| `meaning` | 把图形证据翻译成领域含义 | 超出数据的外推 |
| `conclusion` | 作者想用它证明什么 | 重复 `what` |
| `caveats` | 至少 1 条：n、对照、统计、代表性、外推限制 | “无” |
| `connection` | 上一张图留下什么问题，这一张怎么接上，下一张去哪 | 流水账 |

## 常见图的读法

- **热图**：行/列聚类、色标范围、中心化方式；不要只描述“红/蓝”，要说“哪一组整体更高/更低”。
- **火山图**：横轴效应量、纵轴显著性、阈值线；区分“显著”与“效应大”。
- **箱线图/柱状图**：中位数/均值、误差棒含义（SD/SEM/CI）、散点是否显示、n 数。
- **生存曲线**：删失标记、风险人数表、log-rank P、HR/CI。
- **显微图**：比例尺、染色/通道、代表性与重复数；荧光强度不能只看“亮”。
- **模式图**：箭头方向、抑制/激活符号、虚线含义；模式图是假说，不是数据。
- **模型架构图**：输入→模块→输出，张量维度、重复次数 N、共享权重；区分训练/推理。
- **森林图/回归**：参照组、OR/HR、置信区间、校正变量。

## 图与图的逻辑

不要写“Fig.1 是……Fig.2 是……”。用一条证据链：
> Fig.1 建立体系/提出模型 → Fig.2 拆解关键机制 → Fig.3 在体内/独立队列验证 → Fig.4 解释个体差异 → Fig.5 给出模型/总结。

`overview.logic_summary` 用 2–4 句讲这条链；`overview.flow` 每张图一个“角色”。

## 裁剪检查

- 自动裁剪后必看：图是否完整、有没有混入正文、有没有切掉坐标轴/图例/面板字母。
- 裁错了用：

```bash
python3 crop_figure.py --paper paper.json --list
python3 crop_figure.py --paper paper.json --fig fig2 --bbox x0,y0,x1,y1 --out figs/fig2.png --update
```

- PDF 坐标单位是 pt，原点左上；页面大小见 `--list` 输出。
- 重裁后必须重新打开图片确认，不要只看 bbox 数字。

## 陷阱

- 把“相关”写成“导致”；
- 把模式图/示意图当成实验证据；
- 忽略 n 与重复数，用“显著”覆盖小样本；
- 只看 P 值不看效应量；
- 把补充图里的结论写进主图，或反之；
- 把“作者提出”写成“研究证明”。
