# 交付前检查清单

## 文件

- [ ] `job.md`：短标题、一句话、关键词、3 条要点、期刊/年份/团队/DOI；
- [ ] `job.en2cn.html`：可离线打开；目录覆盖全部章节；书签刷新后仍在；搜索可用；打印/深浅色正常；
- [ ] `job.fig.html`：顶部 Figure 切换；`#fig2` 深链；图片放大；左右方向键；每图都有图例中译/解读/结论/注意事项；
- [ ] `job.method.html`：方法顺序与论文一致；每条有原理/用法/参数/解读/文献链接；
- [ ] `job.weixin.md`：1500–3000 字；每张主图都有；有故事线；标题不夸张；
- [ ] `job.talk.md`：900–1300 字；3–5 分钟能念完；发表信息/团队/期刊/背景/问题/结果/创新点齐全。

## 内容

- [ ] 数字、单位、P 值、n、百分比与原文一致；
- [ ] 没有把“相关”写成“导致”，没有把“提示”写成“证明”；
- [ ] 每张图的 `one_line` 能被图直接支持；
- [ ] `caveats` 不是“无”，而是具体限制；
- [ ] 方法 DOI 能打开且指向正确论文；
- [ ] 作者/团队/期刊/年份与首页或 DOI 页面一致；
- [ ] 公众号文与讲稿没有互相复制粘贴的大段重复。

## 技术

- [ ] `check_outputs.py` 通过（允许 warning，不允许 error）；
- [ ] 所有 `figs/*.png` 存在，HTML 中无裂图；
- [ ] 手机宽度（≈390 px）下：单栏、目录抽屉、图片可读；
- [ ] 打印预览不出现侧栏/按钮；
- [ ] HTML 无 `__DATA__`、`TODO`、`待补充` 等占位。

## 向用户汇报

1. 输出目录与 6 个文件（给可点击路径）；
2. 一句话结论 + 最值得看的 1 张图；
3. 需要人工复核的地方：
   - 自动裁剪 confidence 为 `low/guessed` 的图；
   - 参考文献 DOI 未能在线核验的条目；
   - 原文未写清、你做了保守处理的地方；
4. 如果用户后续要改：优先改 `translation.json` / `figures.json` / `methods.json` 再重跑 builder，不要手改 HTML 里的正文。
