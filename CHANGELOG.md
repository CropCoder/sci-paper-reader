# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-10-21

### Added

- Shared top navigation with page tabs (`reader / figures / methods`) and a module jump menu.
- Fixed 1120 px reading width shared by navigation and body content.
- Figure gallery sidebar and unified hero/section-head layout, matching the reader and methods pages.
- CI, tests, issue templates, contribution and security files.

### Changed

- Global serif typography: Times New Roman for English, Songti/Noto Serif CJK for Chinese.
- WeChat writing rules: each paragraph ≥200 Chinese characters, at most 1–2 questions, stronger
  narrative logic and more specific interpretation.
- Removed the left color bar from the TOC hover/active state.

## [1.0.0] - 2026-10-21

### Added

- Initial release: PDF extraction, bilingual reader, figure gallery, methods page, WeChat article,
  group-meeting talk, JSON schemas and QA script.
